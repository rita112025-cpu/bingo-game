# 🎉 賓果遊戲 Bingo

一個簡單好玩的賓果小遊戲，用純 HTML / CSS / JavaScript 寫成，不需要安裝任何東西或架設伺服器。

## ▶ 開始玩

- 直接開啟 `index.html` 就能在瀏覽器玩
- 啟用 GitHub Pages 後，也可以用網址在線上玩

## 🎮 玩法

1. 點擊「抽號碼」或按**空白鍵**，從 1–75 隨機抽出號碼
2. 抽到的號碼若在你的賓果卡上，會自動圈起來
3. 連成任一直線、橫線或斜線，就是「賓果」！

## ✨ 特色

- 5×5 BINGO 卡（B / I / N / G / O 五欄 + 中央 FREE 格）
- 即時統計：已抽／剩餘／連線數
- 賓果慶祝動畫與彩帶效果
- 可隨時重新開局，賓果後也能繼續挑戰更多連線

## 🛠 技術

- HTML + CSS + JavaScript（單一檔案，無任何相依套件）
